# Broadcom x SpaceXAI

Password-protected GTM leave-behind for Broadcom.

## Local setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Set `SITE_PASSWORD` in `.env.local` before starting the app. The repository
does not contain the shared password.

## Checks

```bash
npm run lint
npm run build
npm run audit
```

The Broadcom wordmark is the official red and black asset published through
[Broadcom Media Resources](https://www.broadcom.com/company/news/resources#assets).
